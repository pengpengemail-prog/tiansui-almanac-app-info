# Tiansui Almanac Support

Last updated: April 25, 2026

## 1. Product scope

Tiansui Almanac is a traditional almanac, date-reference, and Tiansui study app, covering daily almanac references, date selection, element context, and private study notes.

Users may enter birth date, birth time, timezone, and an optional name to receive traditional reference notes for cultural study. The app does not promise personal outcomes or professional advice.

## 2. Common questions

### Does the app require an account?

No. The current MVP does not require account creation or sign in.

### Does the app need an internet connection?

The current version is designed to make the core reference flow available immediately after launch. Study-reference generation is intended to happen locally on device.

### Is this app medical, legal, or financial advice?

No. Tiansui Almanac provides cultural reference and study content inspired by traditional Chinese systems. It is intended for cultural study, self-reflection, and education.

### Is my birth data uploaded?

In the current version, birth-related information is intended to be processed locally on the device for study-reference generation. The current build does not include user accounts, analytics SDKs, ad SDKs, or cloud profile storage.
