# Tiansui Almanac Support

Last updated: April 25, 2026

## 1. Product scope

Tiansui Almanac is a traditional almanac and Four Pillars reference app, covering daily almanac references, date selection, BaZi, Zi Wei, and Five Elements notes.

Users enter birth date, birth time, timezone, and an optional name to receive reflective chart-based guidance about personality, timing, relationships, and energetic balance.

## 2. Common questions

### Does the app require an account?

No. The current MVP does not require account creation or sign in.

### Does the app need an internet connection?

The current MVP is designed to make the core reading flow available immediately after launch. Chart generation is intended to happen locally on device.

### Is this app medical, legal, or financial advice?

No. Tiansui Almanac provides cultural reference and study content inspired by traditional Chinese systems. It is intended for cultural study, self-reflection, and education.

### Is my birth data uploaded?

In the current MVP, birth-related information is intended to be processed locally on the device for reading generation. The current build does not include user accounts, analytics SDKs, ad SDKs, or cloud profile storage.
